# LNG 가격 스프레드

메뉴 `LNG 스프레드`, 직접 링크 `/investing/#/lng`. 기존 화면과 동일한 다크 테마에 첨부 차트의 3개 가격 카드, TTF−HH(파랑)·JKM−HH(주황) 시계열, 출처·기준일을 배치한다. 기본 3년, 1·3·6개월/1년 전환, 범례 토글, 구간 확대, 선택 기간 CSV, 최근 관측값 표를 제공한다. 메뉴는 지연 로딩되고 데이터는 `public/lng/spreads.json`을 읽는다.

## 원천과 계산

Yahoo Finance Chart API의 5년 일별 **close**를 수집한 뒤 최근 3년만 보관한다. 원천의 거래소 시간대로 관측일을 해석하고, 당일 미완료 세션·주말·null·비유한 값·0 이하 가격을 제외한다. 서로 다른 거래소 종가 시각 및 인도월은 동기화되지 않으므로 거래 가능한 차익의 직접 측정값이 아니다. JKM은 선물 연속 시계열이며 현물 평가가격 원본이 아니다.

| 계열 | Yahoo 기호 | 원단위 |
|---|---|---|
| Henry Hub | NG=F | USD/MMBtu |
| Dutch TTF | TTF=F | EUR/MWh |
| Japan/Korea Marker | JKM=F | USD/MMBtu |
| EUR/USD | EURUSD=X | USD/EUR |

TTF(USD/MMBtu) = TTF(EUR/MWh) × 0.2930710701722222 × EUR/USD.
유럽 스프레드 = 환산 TTF − HH. 동북아 스프레드 = JKM − HH.
액화·운송·재기화 비용을 차감하지 않는다. 근월물 롤오버에 따른 불연속이 포함된다.

같은 관측일끼리만 결합하며 가격이나 환율을 전일 값으로 채우지 않는다. 원천 중 일부가 누락된 날은 해당 스프레드만 null이다. 카드는 네 계열의 최신 공통일을 사용하고 차트 역시 그 날짜까지만 표시한다. 기준일이 7일 이상 오래되면 화면에 경고를 표시한다.

변화량은 스프레드의 달러 차이다. 전일은 직전 공통 관측일, 1주는 7일 전, 1개월은 전월 같은 날짜(말일 보정)의 공통 관측값과 비교한다. 해당 날짜가 휴일이면 이전의 가장 가까운 공통일을 사용하되 7일을 넘겨 소급하지 않는다. 비교일은 JSON과 카드 툴팁으로 제공한다. HH 대비 배수는 해외 기준가격/HH이며 스프레드/HH가 아니다.

## 갱신

```sh
python3 scripts/fetch_lng_spreads.py
npm test
npm run build
```

외부 패키지·API 키는 필요 없다. Python 표준 라이브러리로 네 원천을 수집하며 각 원천을 최대 3번 재시도한다. 종목/통화/배열 검증 후 공통 관측값 500개 이상, 최신일 10일 이내, 이전 스냅샷 대비 날짜 후퇴·10% 이상 이력 손실 없음 조건을 통과해야 원자적으로 공개 JSON을 교체한다. 실패하면 이전 파일은 그대로 남고 프로세스는 오류로 종료한다. Yahoo의 JKM alias는 currency=null을 반환할 수 있어 해당 기호만 예외를 둔다.

`Refresh LNG Spreads` GitHub Actions가 매일 08:40 KST에 수집·테스트·빌드 후 데이터 커밋과 Pages 게시를 수행한다. 스케줄은 GitHub 사정으로 지연될 수 있다. 수동 실행도 가능하다. 자동화 실패 시 기존 게시물이 유지된다. 원천 서비스의 제한·형식 변경 시 수집기 유지보수가 필요하다.

## 검증

`tests/test_lng_spreads.py`는 단위 환산, 실제 CSV용 원자료와 전 관측값 재계산, 달력 비교일, 결측 전파, 음수 스프레드, 거래소 날짜, 미완료 세션 제외, 잘못된 통화와 데이터 후퇴 거부를 검사한다. 프론트엔드도 데이터 형식과 기준일/가격 정합성을 검사하고 오류 시 재시도 UI를 제공한다.

초기 게시 검증: 기존 테스트 포함 60개와 TypeScript/Vite 빌드 통과. 375·768·1440px에서 페이지 가로 넘침 없음. 기간 전환·범례 토글·원자료 표·직접 링크 새로고침·기존 Hyperscaler 메뉴·뒤로가기를 브라우저에서 확인했고 콘솔 오류/경고는 없었다. 브라우저에서 내려받은 1개월 CSV 24행을 원본 JSON과 전부 대조했다. 최초 기준일은 2026-09-18, 공통 관측일은 752개다. 기존 ECharts 메인 번들의 크기 안내는 남아 있으며 LNG 화면은 별도 번들로 지연 로딩한다.
